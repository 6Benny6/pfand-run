# Pfand Run
Browser endless runner set on a Berlin street. Player collects Pfand
bottles to afford a Döner, dodges U-Bahn signs, stairs, scooters and
the Kontrolleur. Score is shown as number of Döner earned.

## Constraints
- Plain HTML/CSS/JS, single page, no build step, no API keys, no backend.
- Deploys on GitHub Pages. Emoji and flat shapes, no external assets.
- All tuning values (Döner price, speeds, spawn rates) live in config.js.

## Rules
- See docs/SPEC.md for game rules and scoring. Do not change rules
  without asking.
- Commit after each working step; messages describe what and why.

## Definition of done per step
- Runs by opening index.html. No console errors.
- Goal and score readable within 10 seconds of starting.
